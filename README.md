# 계단 계산기

정해진 개구부와 층고를 기준으로 계단 배치를 검토하는 정적 웹앱입니다.

## 현재 구현

- `index.html`, `styles.css`, `script.js`만으로 실행됩니다.
- 브라우저에서 `index.html`을 열면 바로 사용할 수 있습니다.
- 선택 가능한 방식:
  - 계단참 후 꺾임
  - 일자형
  - 초반 계단참 90도형
- 입력값:
  - 개구부 가로/세로
  - 층고
  - 계단 유효폭
  - 벽/측면 마감
  - 바닥 마감
  - 상부 마감
  - 디딤판 마감
  - 권장 챌판/디딤판 범위
  - 기준 외 단수 허용
- 출력값:
  - 추천 단수
  - 챌판 높이
  - 디딤판 너비
  - 필요 평면 길이
  - 스트링거 평면상 길이
  - 계단참/회전부 사이즈
  - 계단 구성
  - 회전부 계단 수
  - 2R + T 보행식
  - 평면 SVG 미리보기

## 현재 계산 기준

- 기본 권장 챌판: 150-180mm
- 기본 권장 디딤판: 260-300mm
- 보행식 검토: 2R + T = 600-650mm
- 마감 보정:
  - 유효 개구부 = 개구부 치수 - 벽/측면 마감 x 2
  - 보정 층고 = 층고 + 상부 마감 - 바닥 마감
  - 실제 디딤판 = 입력 디딤판 - 디딤판 마감
- 계단참 후 꺾임 방식은 계단실 안에서 계단참/회전부를 지나 180도 돌아 올라가는 U형 계단으로 고정합니다.
- 계단참 후 꺾임 방식의 계단참은 위쪽 벽 중앙 또는 아래쪽 벽 중앙에 배치합니다.
- 계단참 후 꺾임 방식은 아래쪽 직선 구간과 위쪽 직선 구간의 계단 수를 같게 계산합니다.
- 계단참 후 꺾임 방식은 회전부 중심 높이가 전체 층고의 중간 근처에 오도록 계산합니다.
- 회전부 계단 분할선은 아래 계단, 위 계단, 계단참이 만나는 꼭지점을 기준으로 하되 각 칸의 면적이 비슷하도록 나눕니다.
- 계단참 후 꺾임 방식의 회전부 계단 수는 최대 4칸까지만 허용합니다.
- 계단참 후 꺾임 방식의 회전부 계단 수는 자동 또는 1-4칸으로 직접 지정할 수 있습니다.
- `기준 외 단수 허용`을 켜면 권장 챌판/디딤판 범위를 벗어나더라도 추가 단수 후보를 검토합니다.
- 초반 계단참 90도형은 몇 단 후 계단참을 만들지 입력하고, 계단참 이후 왼쪽 또는 오른쪽으로 90도 꺾어 배치합니다.
